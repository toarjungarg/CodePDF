# Changelog

## 1.25.0
- Added LaTeX export (`.tex`, `.sty`, `.cls`).

## 1.24.0
- Added Assembly export (`.s`, `.S`, `.asm`).

## 1.23.0
- Added VHDL export (`.vhd`, `.vhdl`).

## 1.22.0
- Added Verilog and SystemVerilog export (`.v`, `.vh`, `.sv`, `.svh`). Every `.v` file is treated as Verilog.
- Folder export now skips `obj_dir`, `xsim.dir` and `incremental_db` folders.

## 1.21.0
- Added Arduino export (`.ino`). Sketches are coloured as C++.

## 1.20.0
- Added MATLAB export (`.m`). Every `.m` file is treated as MATLAB.
- Folder export now skips `slprj` and `codegen` folders.

## 1.19.0
- Added R export (`.r`, `.R`).
- Folder export now skips `renv` and `packrat` folders.

## 1.18.0
- Added Lua export (`.lua`).
- Folder export now skips `lua_modules` folders.

## 1.17.0
- Added Dart export (`.dart`).

## 1.16.0
- Added Ruby export (`.rb`).

## 1.15.0
- Added Swift export (`.swift`).
- Folder export now skips `Pods`, `DerivedData` and `Carthage` folders.

## 1.14.0
- Added Kotlin export (`.kt`, `.kts`).

## 1.13.0
- Added Shell / Bash export (`.sh`, `.bash`).

## 1.12.0
- Added SQL export (`.sql`).

## 1.11.0
- Added PHP export (`.php`).

## 1.10.0
- Added Go export (`.go`).
- Folder export now skips `vendor` folders.

## 1.9.0
- Added C# export (`.cs`).

## 1.8.0
- Added Java export (`.java`).

## 1.7.0
- Added Rust export (`.rs`).

## 1.6.0
- Added TypeScript export (`.ts`, `.mts`, `.cts`).
- Added React export (`.jsx`, `.tsx`). JSX tags are coloured like HTML.

## 1.5.0
- Added JavaScript export (`.js`, `.mjs`, `.cjs`).
- JavaScript inside HTML `<script>` tags and attributes like `onclick` is coloured too.

## 1.4.0
- Added HTML export (`.html`, `.htm`). CSS inside `<style>` tags is coloured too.

## 1.3.0
- Added CSS export (`.css`).

## 1.2.1
- Optimized file size: the download is about half as big.
- Tidied up small UI details.

## 1.2.0
- Added Python export (`.py`, `.pyw`).

## 1.1.0
- Added C export (`.c`).

## 1.0.0
- First release: PDF viewer and C++ export.
